# 시작하기 (프론트엔드 개발 환경 세팅)

처음 세팅하는 팀원이 위에서부터 순서대로 따라 하면 된다.

---

## 1. 처음 한 번만

### 1-1. 설치
- **Git**: https://git-scm.com
- **Node.js (LTS, v20 이상 권장)**: https://nodejs.org

### 1-2. 코드 받기 및 패키지 설치
```bash
git clone <저장소_주소>
cd GDGoC_project_frontend_repository
npm install
```

### 1-3. 환경변수 설정 (선택)
기본값으로 동작하지만, 로컬 설정을 바꾸려면 `.env.example`을 복사해 `.env`를 만든다.
```bash
cp .env.example .env
```

| 변수 | 설명 |
|---|---|
| `VITE_API_BASE_URL` | 백엔드 API 주소 (기본 `http://127.0.0.1:8000/api/v1`) |

백엔드 서버는 별도로 실행해야 하며, 개발 서버(`http://localhost:5173`)에서 오는 요청을 CORS로 허용해야 한다.

### 1-4. 개발 서버 실행
```bash
npm run dev
```

---

## 2. 주요 명령어

| 작업 | 명령어 | 설명 |
|---|---|---|
| 패키지 설치 | `npm install` | `package.json` 기준 의존성 설치 |
| 개발 서버 실행 | `npm run dev` | Vite 개발 서버 실행 |
| 빌드 및 타입 검사 | `npm run build` | `tsc -b` 타입 검사 후 프로덕션 번들 생성 |
| 빌드 결과 미리보기 | `npm run preview` | `dist/` 빌드 결과물 로컬 실행 |

---

## 3. 평소 작업 흐름

```bash
# 최신 main 반영
git switch main
git pull
npm install

# 기능 브랜치 생성
git switch -c feat/<기능명>

# 작업 후 커밋 & push
git add <파일>
git commit -m "feat: 설명"
git push -u origin <브랜치>
```
